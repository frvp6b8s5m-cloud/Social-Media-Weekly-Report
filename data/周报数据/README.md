# ReelShort 每周数据提交区

## 每周操作

1. 复制 `_每周复制模板` 文件夹。
2. 将副本改名为 `YYYY-MM-DD_YYYY-MM-DD_周报数据`，日期必须为周一至周日。
3. 将各后台原始导出放入对应目录，不修改原始字段或删除数据行。
4. 在 `04_版权保护\版权保护登记表.xlsx` 填写 `YouTube_CID`、`Facebook_RM` 和 `Meta_RM分析` 三个 Sheet。Meta 数据无需另外导出。
5. 在 `05_业务补充` 填写本周特别事项和已确定的下周行动。
6. 文件齐全后，在对话中通知：“本周数据已齐，可以生成周报”。

## 版本规则

- 首次导出使用原文件名。
- 发现导错或发生收入回补时，不覆盖原文件；新增同名 `_v2`、`_v3` 文件。
- 最新版本用于当前值，最早版本保留为首次汇报快照。
- 缺失数据不会按零处理，周报会显示“数据未提供”。

## 已确认的导出格式

- YouTube：每个频道保留后台导出的 `图表数据.csv`、`总计.csv` 和 `表格数据.csv`，可保留后台自动生成的上级文件夹。
- Facebook：每个主页保留 `互动`、`关注次数`、`浏览人数`、`浏览量`、`访问量` 和 `链接点击量` CSV；有收入数据时再增加 `收入.csv`。
- 分销引流：放入当周 `用户数据.csv`。系统仅使用“机构”字段中包含“自营”的记录，并在处理结果中生成 `分销自营账号.csv`。
- 版权保护：Meta 匹配视频数量和屏蔽数量以“万”为单位填写，保留两位小数；平台占比、地区占比和剧目 Top 5 手动填入 `Meta_RM分析`。统计周期自动沿用周文件夹日期，不在表内重复填写。

当前分销导出没有剧目字段，因此只生成自营账号/机构维度漏斗，不生成剧目排名。
